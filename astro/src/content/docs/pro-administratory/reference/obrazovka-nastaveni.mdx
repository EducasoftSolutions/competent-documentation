# Obrazovka Nastavení

Obrazovka **Nastavení** slouží ke konfiguraci systému Competent podle potřeb vaší organizace. Nastavení škálují od jednoduché správy štítků a míst až po řízení komplexních workflow. Obrazovka je organizována do záložek – každá záložka spravuje určitou část konfigurace systému.

<Admonition kind="warning" title="Přístup jen pro proškolené administrátory">

Tato sekce by měla být přístupná jen několika málo proškoleným uživatelům, kteří dobře znají fungování systému Competent. Nesprávná manipulace s nastavením může nenávratně poškodit spravovaná data.

</Admonition>
---

## Přístup k obrazovce

Vstup do obrazovky Nastavení a do jednotlivých záložek je řízen oprávněními. Různé záložky mohou vyžadovat různá oprávnění.

---

## Přehled záložek

Obrazovka Nastavení obsahuje panel s 12 záložkami. Přehled záložek v pořadí, v jakém se zobrazují v rozhraní:

| Záložka | Popis |
|---------|-------|
| [**Místa**](/pro-administratory/reference/tab-mista/) | Správa sdíleného číselníku míst (adres), která lze přiřazovat objektům v systému. |
| [**Štítky**](/pro-administratory/reference/tab-stitky/) | Správa štítků sloužících ke klasifikaci aktivit. |
| **Menu** | Samostatná dokumentace se připravuje. |
| **Role** | Správa rolí a oprávnění. Viz také [Přehled rolí a oprávnění](/pro-administratory/reference/prehled-roli-a-opravneni/) a [Role: model a principy](/pro-administratory/concepts/role/). |
| [**Subtypy**](tab-subtypy.md) | Správa subtypů aktivit a dalších objektů. |
| [**Parametry**](tab-parametry.md) | Správa parametrů hlavních objektů Competentu. |
| [**Přiřazení dle skupin**](/pro-administratory/reference/tab-prirazeni-dle-skupin/) | Pravidla automatického přiřazování objektů uživatelům na základě příslušnosti ke skupinám. |
| [**Šablony e-mailů**](/pro-administratory/reference/obrazovka-sablony-emailu/) | Správa skupin e-mailových šablon. |
| [**Notifikace**](/pro-administratory/reference/tab-notifikace/) | Správa globálních notifikací (událost, šablona, příjemci). |
| [**Koš**](/pro-administratory/reference/tab-kos/) | Obnova a trvalé odstranění dříve smazaných objektů. |
| **Workflows** | Samostatná dokumentace se připravuje. |
| **Superadmin** | Samostatná dokumentace se připravuje. |

Záložky Menu, Workflows a Superadmin slouží k pokročilejší konfiguraci systému; jejich samostatná dokumentace se připravuje.
